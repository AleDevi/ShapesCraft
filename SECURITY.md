# Security policy

ShapesCraft is a static web app: it runs entirely in your browser, has no server
and does not upload your photos anywhere.

## Supported versions

Only the version currently published at https://aledevi.github.io/ShapesCraft/
(the `main` branch) receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report it privately through GitHub instead:
[Report a vulnerability](https://github.com/AleDevi/ShapesCraft/security/advisories/new)
(Security tab → "Report a vulnerability").

Include what you found, how to reproduce it, and the browser/device you used.
You should get a first reply within 7 days. Once the issue is fixed, a security
advisory will be published and you will be credited, unless you prefer otherwise.
